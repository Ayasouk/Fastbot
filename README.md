# FastBot: Your Solana Trading Companion 🚀
## Welcome to FastBot, the ultimate Telegram bot designed to streamline your Solana trading experience. Whether you're tracking wallet activities, fetching token prices, or managing your portfolio, FastBot is here to assist you with speed and precision.
Features 🌟
- Track Solana Wallets: Stay updated with real-time notifications on wallet activities.
- Stop Tracking: Easily pause or remove wallets from your tracking list.
- List Tracked Wallets: View all the wallets you're currently monitoring.
- Fetch Token Prices: Get the latest prices for your favorite tokens.
- Secure Wallet Management: Encrypt and store your private keys securely.

## How It Works 🔧
FastBot leverages the power of WebSockets and MongoDB to provide seamless and efficient tracking of Solana wallets. With a robust backend and a user-friendly Telegram interface, managing your crypto assets has never been easier.

### Getting Started 🚀
1. **Clone the Repository:**
```
   git clone https://github.com/yourusername/fastbot.git
```
2. **Install Dependencies:**
```
   pip install -r requirements.txt
```
3. **Set Up Environment Variables:**

Create a .env file with your API keys and database credentials. Example:
```
   TELEGRAM_API_KEY=your_telegram_api_key
   MONGO_USERNAME=your_mongo_username
   MONGO_PWD=your_mongo_password
   SOLANA_RPC_URL=your_solana_rpc_url
   MORALIS_KEY_API=your_moralis_api_key
   ENCRYPTION_KEY=your_encryption_key
   API_KEY=your_api_key
```

4. **Run the Bot:**
```
   python main.py
```
